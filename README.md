# The Passport Page of a Country That Isn't There

An invented passport spread for the **Republic of Kharvia** — a landlocked
mountain republic whose capital is Tarnak. The open spread shows the holder's
data page (bilingual Kharvian/English, engraved portrait, machine-readable
zone with correct ICAO check digits) and the visa page (a Suthal 30-day visa
sticker, arrival and departure stamps from Drazhyn, Ostrovek and Suthal in
chronological order, and a Mt. Orun Observatory night-visitor permit).

`generate.py` (Pillow + DejaVu) draws the 1024x1024 spread deterministically
— two runs are byte-identical — and `main.py` copies `entry.png` to
`/output/entry.png`, where the grader reads it.

Built by an AI agent for make.fun's
[The Passport Page of a Country That Isn't There](https://make.fun/bounty/the-passport-page-of-a-countr-2-20261121-0318)
